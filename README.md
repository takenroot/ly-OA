# 纸质收料单 → Excel 日报(每天跑一次)

## 流程

```
示例车间A/2026年8月11日/*.jpg  (输入,每个车间一个根目录)
        ↓
  按车间名匹配 workshops/车间.json 版式配置
        ↓
  整图 OCR + label 锚定取值(印章/拍照偏移不影响)
        ↓
  字段校验,可疑字段在 Excel 标黄
        ↓
示例车间A/2026年8月11日/固废填埋日统计表0811.xlsx  (输出,每个车间/date 目录一份)
```

## 快速开始

### 图形配置界面(推荐)

打包后双击 `ly-oa.exe` 即可打开配置界面,设置数据源根目录,
并开启/关闭定时任务,或手动跑一次指定日期的日报。日报默认输出到各数据源目录下。

```bash
# 开发模式启动 GUI
uv run python run.py
# 或显式
uv run python run.py --gui
```

### 命令行

```bash
# 跑某一天
uv run python -m src.main --input ./示例车间A/2026年8月11日
# 显式指定日期(覆盖目录名解析)
uv run python -m src.main --input ./示例车间A/2026年8月11日 --date 2026-08-11
```

成功后:

- 每个车间/date 目录生成一份 `固废填埋日统计表{MMDD}.xlsx`(MMDD = 月日补零,如 0811)
- 参考模板 `参考模板/固废填埋日统计表0809.xlsx` 不动(只读样式来源)
- 识别失败或标黄的行,备注列会带照片超链接,可直接点击原图人工核对。**源图片永远不动**
- 日志按天写入 `logs/ly-oa_{YYYYMMDD}.log`

## 目录约定

| 路径                         | 用途           |
| -------------------------- | ------------ |
| `示例车间A/2026年M月D日/*.jpg`     | 输入,按车间+日期分目录 |
| `示例车间B/2026年M月D日/*.jpg`       | 输入,另一车间示例 |
| `车间/日期/固废填埋日统计表{MMDD}.xlsx` | 输出,每个车间/date 目录一份 |
| `参考模板/固废填埋日统计表0809.xlsx`   | 样式参考,只读      |
| `logs/ly-oa_{YYYYMMDD}.log`    | 按天文本日志(逐张明细 + 每次运行汇总) |
| `workshops/车间名.json`         | 车间版式配置文件 |

## 字段映射(收料单 → Excel)

| 源字段           | Excel 列 | 转换                            |
| ------------- | ------- | ----------------------------- |
| 编号 `XMG...`   | 备注(J)  | 完整编号显示在备注,同时备注列带照片超链接;日期优先从目录名解析,不再依赖编号 |
| **检毛时间**      | 装车时间(C) | 固定优先取 `检毛`;取不到时用 `检皮` 兜底,与车间 date_field 解耦 |
| 物资(石渣/石膏)     | 货品名称(D) | 固定 `石膏废渣`                     |
| 车号 `京A00000A` | 车牌号(E)  | 字符串                           |
| 司磅员          | 司机姓名(F) | 置空(同原文件)                      |
| 皮重 (kg)       | 皮重(G)   | /1000 → 吨                     |
| 毛重 (kg)       | 毛重(H)   | /1000 → 吨                     |
| 净重 (kg)       | 净重(I)   | /1000 → 吨                     |

备注(J)列带原图照片超链接。识别失败/低置信的字段在 Excel 里**标黄**。

不同车间的标签名不同,在 `workshops/车间名.json` 里配置别名,例如示例车间B的 `车牌号` → `车号`、`毛重时间` → `检毛`。

## 配置文件 (`config.ini`)

```ini
[paths]
reference_xlsx = ./参考模板/固废填埋日统计表0809.xlsx
template = ./template.json
log_dir = ./logs

# 数据源根目录,每个车间一个
input_roots = ./示例车间A, ./示例车间B

# centralized 日报输出目录(隐藏/可选,默认输出到各数据源目录)
; 日报_dir = ./日报

[ocr]
confidence_threshold = 0.85

[driver]
# 留空 = 司机姓名置空(同原文件)
default_driver_name = 
```

## 识别原理与调优

主路径(`src/locate.py`):**整图 OCR 一次,靠单据印刷 label(编号/车号/毛重...)锚定取值**。
对拍照偏移、表格线检测漂移、印章位置都免疫。`template.json` 比例裁剪只是
label 找不到时的兜底,不要当主路径调。

识别出问题时先跑诊断,分清「框切错」还是「OCR 读错」:

```bash
uv run python scripts/debug_rois.py --input ./示例车间A/2026年8月11日
# 标注图写到 ./debug_rois/(绿=达标,红=失败/低置信)
```

已知限制:

- 印章完全盖住字段时识别不出 → 该字段标黄,点击备注列照片超链接人工补录
- 严重透视倾斜的照片 OCR 框可能错位(透视矫正未实现,需要时再加)

## 运行模式

```bash
uv run python -m src.main --auto              # 跑昨天(定时任务用)
uv run python -m src.main --day 2026-08-11    # 补跑/复现指定日期
uv run python -m src.main --input <目录>      # 单目录调试
```

`--auto`/`--day` 扫描 `config.ini` 的 `input_roots`(**多个车间逗号分隔**),
每个车间/date 目录**分别生成**一份日报。`logs/ly-oa_{YYYYMMDD}.log` 包含每张图片的识别明细与每次运行的汇总
(图片数/成功/失败/标黄/状态),当天无数据记"无输入"、程序异常记"异常"
(详情仍在 `errors.log`)——每天看最后一行汇总就知跑没跑成。

## Windows 部署(exe + 任务计划)

打包必须在 Windows 上进行(PyInstaller 不能跨平台)。在仓库根目录:

```bat
scripts\build_exe.bat     :: 产出 dist\ly-oa.exe
```

部署目录结构(首次运行会自动释放配置文件,所以只需复制 `ly-oa.exe`,如放到 `D:\ly-OA\`):

```
D:\ly-OA\
  ly-oa.exe               ← 唯一需要复制过来的文件
  config.ini              ← 首次运行自动释放,路径/数据源在这里改
  template.json           ← 首次运行自动释放
  使用说明.txt             ← 首次运行自动释放
  参考模板\固废填埋日统计表0809.xlsx   ← 首次运行自动释放
  workshops\              ← 首次运行自动释放
    示例车间A.json
    示例车间B.json
  示例车间A\2026年M月D日\   ← 数据源1,每天一个目录
  示例车间B\2026年M月D日\     ← 数据源2
```

然后:

1. 双击 `ly-oa.exe` 打开配置界面,设置数据源根目录,
   并启用定时任务(默认每天 08:30 跑前一天)。
2. 如需手动补跑/复现某一天,使用 `scripts\补跑.bat`。

注意:任务计划时电脑关机的当天不会自动补,用 `补跑.bat` 补;验证任务可用
`schtasks /run /tn "收料单日报"` 手动触发一次。

`scripts\install_task.bat` 仍可单独使用,功能与 GUI 中的"启用定时任务"相同。

## 默认行为(用户不配置时生效)

- **双击 `ly-oa.exe`**：打开图形配置界面，不会自动开始识别。
- **输出位置**：默认写到每个 `车间/日期/` 目录下，不按 centralized `日报_dir` 输出。
- **统计表标题**：读取数据源目录名作为车间名，替换参考模板标题中的 `"示例车间A"`，得到 `"XX公司XX区域{车间名}一般固废填埋日统计表"`。
- **照片方向**：优先 0° 识别；仅当 0° 无法完整拿到日期、车牌、毛重、皮重、净重，或出现标黄/警告时，才继续尝试 90°/180°/270° 并选最优。
- **识别失败**：仍会往 Excel 写入空记录，备注列带原图超链接，源图片不会被移动或删除。
- **置信度阈值**：默认 `0.85`，低于此值的字段标黄。
- **司机姓名**：默认留空；可在 `config.ini [driver] default_driver_name` 中固定填写。
- **定时任务**：默认每天 `08:30` 跑前一天；通过 GUI 启用/停用。
- **手动执行**：GUI 中可点“跑昨天”或输入日期后点“跑指定日期”，不用去命令行。
- **CPU 占用**：OCR 引擎限制为最多 2 个线程，避免单张识别占满所有核心。
- **`--help`**：命令行输入 `ly-oa.exe --help` 可查看参数说明(windowed exe 下会弹窗显示)。
- **完成通知**：手动跑或定时任务跑完后，Windows 右下角会弹出通知，显示成功/失败/标黄数量。
